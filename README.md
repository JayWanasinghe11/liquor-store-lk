## 🚀 Features
- **Age Verification:** Secure age gate before entering the store.
- **Real-time Store:** Drinks are fetched live from Firebase Firestore.
- **Smart Cart:** Seamless shopping experience using Provider State Management.
- **AI Sommelier:** Integrated AI chat to help users choose their drinks.
- **Checkout Flow:** Cash on delivery order placement system.
- **Dark UI:** Sleek, glassmorphism-inspired futuristic design.

## 🛠️ Tech Stack
- **Frontend:** Flutter (Dart)
- **State Management:** Provider
- **Backend:** Firebase (Firestore)
- **Security:** Environment Variables (`.env`) for API keys.
- **Fonts:** Google Fonts (Oswald & Inter)
